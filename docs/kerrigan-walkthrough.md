# Разходка с Kerrigan — какво да ѝ кажеш във всяка фаза

Сценарий за тест на целия процес: малък калкулатор на JavaScript, създаден от нулата в
`C:\Projects\calculator-test` — празна папка с git хранилище и един празен комит. Без външни
зависимости и без npx; тестовете са `node:test` и вървят с `npm test`.

Репликите по-долу са твоите. Тя пита с фиксирани съобщения — едни и същи при всеки разговор, в
един и същ ред, с номера 1, 2, 3 и опции 1.1, 1.2 (никога букви). Първият ред на всяко съобщение е
редът за фазата. Текстът им е в `src/plan/script.ts`; ако съобщение се различава от него — въпрос в
повече, друг ред, букви вместо номера, различен ред за фазата — запиши го като отклонение. Отговаряш
под номера на всеки въпрос, а на изборите — с номера. Редовете в курсив, които започват с *Пример:*,
са само ориентир.

**Внимание:** удебелените бележки в този файл („Внимание", „Проверка", „Очаквано") са за теб, не за
нея — не ги поставяй в чата.
